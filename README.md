# Agentic Deployment Specification

> An open specification for agentic deployment of self-hosted applications.

## Vision

Applications should be able to describe how AI agents deploy, configure and operate them.

Today every deployment agent has to reverse-engineer repositories.

ADS changes that.

Applications become self-describing.

## Goals

- Vendor neutral
- Human approval by default
- Self-hosting first
- AI-native
- Open standard
